# React task # 4

A modern web application built with Astro, React components, and Bootstrap.

## 🚀 Quick Start

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone [repository-url]
cd [project-directory]
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Start the development server:
```bash
npm run dev
# or
yarn dev
```

## 📦 Project Structure

```
/
├── public/
│   └── vendor/
│       └── bootstrap/
├── src/
│   ├── components/
│   │   └── home/
│   ├── content/
│   └── shared/
└── package.json
```

## 🛠️ Technologies Used

- [Astro](https://astro.build)
- React
- Bootstrap
- TypeScript

## 🔧 Configuration

The project uses several configuration files:
- `tsconfig.json` - TypeScript configuration
- `cloudcannon.config.yml` - CloudCannon CMS configuration
- `src/content/config.ts` - Content collections configuration

## 🚀 Deployment

Build the project for production:

```bash
npm run build
# or
yarn build
```
